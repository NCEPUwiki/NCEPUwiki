# 进阶贡献

## 文件结构

写文章只需要关注`docs/.vuepress/public/`和**有编号**的文件夹，如`01.新生入学/`，其余内容请自行查看相关项目文档或者询问AI，但是修改需谨慎。

`docs/.vuepress/public/`里面是一些文章引用的图片等资源；**有编号的文件夹**里面的 `.md` 文件就是网站上的文章。

图片放在`docs/.vuepress/public/img/文件夹编号/文章编号`，其余资源类似，以此类推。

以下结构并不全面，只显示一些比较重要的，更深入的了解网站结构请自行访问Github

```text
NCEPUwiki/
├─ docs/                     # 站点正文，最重要的目录
│  ├─ .vuepress/             # VuePress 站点配置
│  │  ├─ public/             # 静态资源
│  │  │  └─ img/             # 图片资源
│  ├─ index.md               # 首页内容
│  ├─ 01.新生入学/            # 新生向内容
│  │  ├─ 01.新生-入学准备.md
│  │  ├─ ...
│  │  └─ 10.Q&A.md
│  ├─ 02.学习专题/            # 学习与升学专题
│  │  ├─ 01.北京校区专业指南/
│  │  └─ ...
│  ├─ ...
│  └─ 10.贡献/                # 给贡献者看的协作说明
```

## 项目贡献流程

### Github Fork

如果你是**第一次**贡献，请先将项目Fork到个人仓库然后进行贡献

![git_fork01](/img/10/02/git_fork01.png)

Fork后会在个人仓库看见 NCEPUwiki Repository，即为Fork成功。

### 01.同步修改

由于wiki更新频率较高，在进行修改前请先通过 Sync fork 同步他人的修改。

![sync_fork](/img/10/02/sync_fork.png)

### 02.编辑内容

在同步之后，可以直接在Github网页对文件进行修改，如删除、添加，这种情况适用于自己先写好文章，最后只需要上传一下。

![edit_contents01](/img/10/02/edit_contents01.png)

也可以使用 Git 工具（此工具的使用请参考文章 [Git教程](/pages/GitStudy/)），将项目 clone 到本地修改，最后在同步到**个人仓库**。

![edit_contents02](/img/10/02/edit_contents02.png)

### 03.提交Pull Request

将修改内容同步到**个人仓库**后，点击仓库主页的 Contribute -> Open pull request ，即可将你的修改提交到NCEPUwiki主仓库，等待项目管理员审核批准，若有问题会及时评论，请及时修改。

![PR](/img/10/02/PR.png)

更详细的流程请参考文章 [Git教程](/pages/GitStudy)的结合Github、Vscode和git进行项目开发 部分
