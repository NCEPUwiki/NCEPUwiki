# 电厂就业

## 分班

一般情况下，如果初到电厂，大概率是要分到运行和检修的。这些都属于一线的范畴。通常情况下，运行是需要倒班，而检修虽然不用倒班，但是也有**值班**制。所以没有说哪个更好哪个更差，一般还是得看个人的选择的。

## 倒班机制

一般听说有什么**x班y倒**，那么x就是轮回的天数，y则是上班的天数。但是也不能简单地理解为上x休(x-y)。

因为像电厂这种地方危险系数是比较高的，所以需要进行安全学习，具体的形式还要看各个厂。所以“休息”日叫回来学习也是存在这种可能的。

还有的厂存在有单循环、双循环等，因为我没有遇到过双循环，所以不清楚具体的运作。建议询问清楚对方厂的倒班机制。

## 考试

既然存在一定的危险系数，那么考试也是不可少的。形式也比较多，有安规、运规考试等等，具体次数也要看各个厂的安排。

## 职称和等级鉴定

等级鉴定是对应工种下的等级的认定。一般分为**初级工**、**中级工**、**高级工**、**技师**、**高级技师**。现阶段的认定条件比较宽松，甚至可以直接报考高级工。但是不同地区、不同企业政策不相同，建议询问清楚再报名。

职称的话，一般上岗一定期限就可报名**助理工程师**，同样是建议时刻关注消息，避免错过。
