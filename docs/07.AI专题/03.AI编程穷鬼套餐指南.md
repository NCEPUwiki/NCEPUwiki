## 为什么会有“穷鬼套餐”

## 一、ChatGPT Plus：能用满额度，就是最划算的

[ChatGPT Plus](https://chatgpt.com/explore/plus) 是 OpenAI 的个人订阅，$20/月。它给你的不只是网页版 ChatGPT，还包含 **Codex**——OpenAI 官方的编码智能体，覆盖网页、桌面端、CLI、IDE 扩展和 iOS。

对“穷鬼”来说，Plus 的价值在于：**你拿到的是当前第一梯队的编码模型，加上一整套完整的智能体能力**，而月费只有 $20。

### 为什么说能用满额度就最划算

Plus 的限额按“每 5 小时多少条本地消息”估算，不同模型差距极大：

| 模型 | 本地消息数 / 5 小时 |
| --- | --- |
| GPT-6 Luna | 350–3,000 |
| GPT-6.1 Sol | 15–160 |
| GPT-6 Sol | 15–150 |
| GPT-6 Astra | 5–45 |

同一份 $20 的月费，你能拿到的东西包括：

- **顶级编码模型**：GPT-6.1 Sol、GPT-6 Sol、GPT-6 Astra 与 GPT-6 Luna。遇到复杂重构、长链路调试这类硬骨头，它们明显强于开源模型——这是订阅费花得最值的地方；
- **全套智能体能力**：Cloud chats、GitHub PR 自动 review、Slack / Linear 集成、Scheduled tasks、Skills / Plugins / MCP、Subagents、Git Worktrees、沙箱与权限控制；
- **多端可用**：Codex CLI、桌面端本地会话、IDE 扩展、手机端远程控制；
- **触顶后还能续**：Plus 用户撞到用量上限后，可以直接购买 ChatGPT credits 继续干活，**不需要升级套餐**；也可以临时改用 API Key 跑本地会话，按 API 价格计费。

换句话说，只要你每周都能稳定用掉一部分额度，$20 摊到实际产出上，比任何按量付费都便宜。

### 怎么把额度用满

额度是**共享**的：本地消息和云任务算同一份，Fast 模式按 **2.5 倍**消耗订阅额度（Ultrafast 是 8 倍，但仅限 Pro $500 起）。所以“用满”的关键不是猛刷，而是别把额度浪费在低价值任务上：

- **模型别选太猛**：日常杂活用 GPT-6 Luna（350–3,000 次 / 5 小时）就能覆盖；GPT-6 Astra 一次任务可能就吃掉 5–45 的额度，留给真正难的问题；
- **别默认开 Fast**：Fast 按 2.5 倍消耗，只有真的赶时间时才开；
- **控制上下文体积**：提示词写精准，别把整个仓库都塞进去；`AGENTS.md` 可以按目录拆分嵌套，减少每次注入的上下文；
- **MCP 服务器按需开**：每个 MCP 服务都会给消息加上下文，不用时关掉；
- **任务拆小**：一次让它干一件明确的事，比丢一个模糊的大任务更省额度。

### 怎么开始用

1. 到 [chatgpt.com](https://chatgpt.com/) 注册账号并订阅 Plus（$20/月）；
2. 安装 Codex CLI（需 Node.js 22+）：

   ```bash
   npm install -g @openai/codex
   ```

3. 在项目目录运行 `codex`，首次启动会引导你登录 ChatGPT 账号；
4. 建议先跑 `/init` 生成 `AGENTS.md`，让它记住你的项目结构和代码规范；
5. 想随时掌握余量：会话里用 `/status`，或打开[用量面板](https://chatgpt.com/codex/settings/usage)。

> **时效提示：** GPT-5.5 将于 2026-10-14 从 ChatGPT、ChatGPT Work 与 Codex 全平台退役；模型档位与额度估算会随版本调整，请以用量面板的实际显示为准。GPT-6.1 Sol 目前仅在 Work 和 Codex 中提供，Chat 对话里选不到。

### 适合你的场景

- 每天都在写代码，每周能稳定消耗掉一部分额度；
- 不想折腾多渠道，一个订阅覆盖 CLI、IDE、网页和手机；
- 需要顶级模型处理复杂重构、疑难 Bug 和长链路任务。

## 二、Command Code Go：$1 一个月的入门券

[Command Code](https://commandcode.ai/) 是一个终端里的编码智能体，命令行工具名叫 `command-code`，主打“会越用越懂你”的 Taste 学习机制。它对穷鬼最友好的地方在于入门档便宜到离谱。

### 价格与额度

| 套餐 | 价格 | 含额度 | 说明 |
| --- | --- | --- | --- |
| Go | $1/月 + 手续费 | $10 额度 | 叠加优惠后约可用到 $15 |
| Max | $100/月 + 手续费 | $150 额度 | 面向高频重度用户 |
| Provider API | $15/月 + 手续费 | 按量付费、无加价 | 想接自己的客户端时用 |

Go 档官方标注约 **9K 次请求**。对写作业、做课设这种量级，Go 基本够用一个月。

### 能用到哪些模型

Go 的额度不是“随便花”，而是**按模型分配**：官方会给一批模型各配 $10 的额度，包括 GLM-5.2、腾讯 Hy3、Qwen 3.8 27B、Qwen 3.7 Max、Qwen 3.7 Plus、DeepSeek V4.1 Flash 等，另外还有 Kimi、MiniMax、MiMo、Step、Inkling、Nemotron 等二十多个模型。

更关键的是，Go 档还有**完全免费、不限额度**的模型兜底：Laguna S 2.1、Ling 3.0 Flash、Ling 3.0 Flash Sante、Ling 3.1 Flash、Glyph Cluster。也就是说，就算那 $10 额度用完了，也不至于彻底开不了工。

代价是：Go 档**不开放 API 访问**，也没法用 GPT、Claude 这类闭源顶级模型。想要 API 就得单独订 Provider API 档（$15/月）。

### 怎么开始用

Command Code 是 Node.js 工具，先装好 Node.js，然后：

```bash
npm i -g command-code
```

安装完成后，到 [commandcode.ai](https://commandcode.ai/) 注册账号并订阅 Go 档（$1/月那档），在终端里进入你的项目目录，直接运行：

```bash
cmdc
```

首次运行会引导你登录并选择模型。日常几条命令就够：

- 想看有哪些模型、当前额度用了多少，在会话里用斜杠命令查询；
- 想先规划再动手，切到 **Plan Mode**；
- 想放开手脚不逐条确认，用 **Auto-Accept Mode**；
- 不想占着终端，跑 **Headless Mode** 或放进**后台沙箱**。

### 适合你的场景

- 只想花“一瓶可乐的钱”验证 AI 编程到底值不值得；
- 主要跑开源模型，对 GPT、Claude 顶级模型没有硬需求；
- 需要一个顺手、能自己学项目“品味”的终端 Agent。

## 三、OpenCode Go：开源编码模型的稳定通道

[OpenCode](https://opencode.ai/) 是一个开源 AI 编程智能体，有终端 TUI、桌面端和 IDE 扩展三种形态。它的订阅叫 **OpenCode Go**，定位是“稳定拿到热门开源编码模型”。

### 价格与限额机制

OpenCode Go 目前只有一档：**$10/月**。

Go 的限额不是“每月多少次”，而是**每月多少美元**，并且按模型分别计算。每个模型的月度上限大致是：

| 模型档位 | 月额度 | 举例 |
| --- | --- | --- |
| 主推档 | $60 | GLM-5.3-Flash、Kimi K2.7 Code、MiniMax M3、MiMo-V2.6-Flash、DeepSeek V4.1 Flash |
| 中档 | $30 | Qwen3.8 Flash、DeepSeek V4 Flash、Space Bunny、Hy4 preview |
| 旗舰档 | $15 | GLM-5.3、Kimi K3、Qwen3.8 Max、Grok 4.7、Claude Haiku 5.5、GPT 6 Luna |

额度按 **5 小时 / 周 / 月**三级控制：5 小时上限是月额度的 20%，周上限是 50%，月上限才是 100%。所以短时间内猛刷会先撞到 5 小时墙。

### 超限之后怎么办

这是 Go 最厚道的一点：**撞到额度上限后，仍然可以继续用免费模型**，比如 LongCat 2.5 Preview Free、Step 5 Preview Free（限时免费、用量无限）。另外如果你在 Zen 账户里还有余额，可以在控制台打开 **Use balance**，超限后自动回落到 Zen 余额继续跑，而不是直接被拒。

### 怎么开始用

安装（Windows 建议用 WSL，体验最好）：

```bash
# 通用安装脚本（macOS / Linux / WSL）
curl -fsSL https://opencode.ai/install | bash

# 或者用 Node.js
npm install -g opencode-ai
```

Windows 原生环境也可以用 Chocolatey 或 Scoop：

```bash
choco install opencode
# 或
scoop install opencode
```

装好后在项目目录运行 `opencode`，然后：

1. 输入 `/connect`，选择 **OpenCode Go**，按提示打开浏览器登录并复制 API Key，粘贴回终端；
2. 输入 `/models` 查看并选择 Go 提供的模型（模型 ID 形如 `opencode-go/kimi-k3`）；
3. 首次使用建议先跑 `/init`，让它生成 `AGENTS.md`，记住你的项目结构和代码风格。

订阅只有一个限制：**同一个工作区里只有一名成员能订阅 Go**。它是完全可选的，你不订阅也能用 OpenCode 接别人的模型。

### 适合你的场景

- 已经在用或打算长期用 OpenCode；
- 想稳定访问 GLM、Kimi、MiniMax、Qwen、DeepSeek 这些开源编码模型；
- 愿意花 $10 换“不用自己折腾多渠道”。

## 四、白嫖路线一：OpenRouter 免费模型

[OpenRouter](https://openrouter.ai/) 是一个模型聚合网关，把各家模型统一成 OpenAI 兼容接口。它有一批以 **`:free`** 结尾的免费模型，是穷鬼的经典粮仓。

### 免费额度和限制

| 已购买额度（累计） | 每分钟请求 | 每天请求 |
| --- | --- | --- |
| 少于 $10 | 20 次 | 50 次 |
| 至少 $10 | 20 次 | 1000 次 |

也就是说，白嫖党每天 **50 次**、每分钟 20 次。有两点要清楚：

- 这是**免费模型的总池子**，不是每个模型 50 次；多开几个账号或密钥也不会提高额度，官方是按全局容量控制的；
- 花 $10 把日限额从 50 提到 1000，性价比其实很高，属于“小额充值解锁”。

免费模型会随时上下线，以 [openrouter.ai/models?max_price=0](https://openrouter.ai/models?max_price=0) 为准。截至 2026-10，`:free` 模型大致有这些：

| `nvidia/nemotron-3-ultra-550b-a55b:free` | 1M |
| `nvidia/nemotron-3-super-120b-a12b:free` | 256K |

其中 Cohere North Mini Code、Poolside Laguna、Thinking Machines Inkling 这几个是“编码向”，适合放进编码 Agent 里；Gemma 和 Nemotron 系列更偏通用。

还有一个偷懒入口：模型 ID 填 **`openrouter/free`**（Free Models Router），路由会自动替你挑一个可用免费模型，省得自己比对。

### 怎么接入

1. 到 [openrouter.ai](https://openrouter.ai/) 注册，在 [Keys 页面](https://openrouter.ai/settings/keys)创建 API Key；
2. 基础地址是 `https://openrouter.ai/api/v1`，协议与 OpenAI 完全兼容，因此**任何支持 OpenAI 接口的客户端都能接**；
3. 模型名直接填上面的 `:free` ID 即可。

以 OpenCode 为例，在 `opencode.json` 里配置（也可以用 `/connect` 选择 OpenRouter 后填密钥）：

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "openrouter": {
      "options": {
        "apiKey": "{env:OPENROUTER_API_KEY}"
      }
    }
  }
}
```

之后用 `/models` 选择 OpenRouter 下的免费模型。同理，Cherry Studio、Cline、Roo Code 等插件，以及[学校本地模型](/pages/ai-coding-llm/)那套客户端，都能用同样的地址和协议接进来。

### 使用注意

- **免费模型不稳定**是常态：限流、排队、偶尔 429，重试时记得加退避；
- **隐私**：OpenRouter 默认不记录你的提示词和补全内容，会记录日志的提供方默认不会被路由；但免费模型里个别会用于改进模型，敏感信息不要丢进去；
- 免费额度是“共享容量”，别拿它跑批量长文生成，容易被限流。

## 七、常见问题与避坑

**Q：ChatGPT Plus 和 Claude Code、Codex 的开源替代有什么区别？**
A：Plus 走的是 OpenAI 自家顶级模型（GPT-6 系列），编码能力是第一梯队，遇到极难的复杂重构优势明显；代价是 $20/月，且额度用不满就浪费。Command Code Go / OpenCode Go 走的是开源模型（GLM、Kimi、MiniMax、Qwen、DeepSeek），价格低一个数量级，日常任务够用，但硬骨头啃不动。**判断标准很简单：你每周能不能稳定用掉 Plus 的额度，能就上 Plus，不能就往下走。**

**Q：Plus 额度够用吗？**
A：看模型。GPT-6 Luna 每 5 小时有 350–3,000 条，日常绝对够；GPT-6.1 Sol 是 15–160 条，GPT-6 Astra 只有 5–45 条，得省着点。用量面板（`/status`）能随时看余量，建议每周看一两次，摸清自己的节奏。

**Q：Plus 撞到上限怎么办？**
A：不用升级套餐。Plus 用户可以直接买 ChatGPT credits 继续；也可以临时改用 API Key 跑本地会话，按 API 价格计费。正在进行的对话允许你干完当前这一轮。

**Q：为什么同样是 5 小时制，Plus 没有“周额度”的说法？**
A：Plus 的估算口径是“每 5 小时多少条本地消息”，官方明确说周限额可能另行适用，具体以用量面板为准。Pro 档目前没有 5 小时限制。

**Q：免费模型能调工具吗（Function Calling / Tools）？**
A：多数可以，`tools` 是常见支持项。但免费模型能力参差，工具调用稳定性明显不如付费档。如果 Agent 频繁“忘了调工具”，优先换模型，而不是怀疑配置。

**Q：会不会用着用着我的额度莫名其妙没了？**
A：会。额度消耗与模型档位强相关，越高级的模型烧得越快。OpenCode Go 是按美元计费的，建议定期看控制台用量；Command Code Go 也是按模型分额度的，别一上来就死磕旗舰档。

**Q：订阅了但客户端连不上 / 报错怎么办？**
A：先确认用的是对应平台的正规客户端或已适配客户端。特别提醒：OpenCode Go 对客户端的**会话头**有要求，官方列出了一批“已验证可用”和“已知有问题”的客户端；尤其是 **DeepSeek Harness 目前属于后者**——部分模型路径会上报会话信息、部分不会，属于官方仍待修复的问题，用它接 OpenCode Go 时要有心理准备。

**Q：免费模型这么多，怎么选？**
A：编码 Agent 优先选**编码向**模型（Cohere North Mini Code、Poolside Laguna、Thinking Machines Inkling、Kimi/MiMo 系列）；通用问答随便挑 Gemma、Nemotron。拿不准就用 `openrouter/free` 让路由替你决定。

**Q：价格和模型清单多久变一次？**
A：很快。本文只是给你一个“值不值得买”的判断框架，具体数字请以官方页面为准。
