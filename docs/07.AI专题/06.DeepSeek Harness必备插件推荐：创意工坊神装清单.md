## 逐一拆解：这 8 款插件具体使用场景？

### 1. `dsh-market`：真正的“Steam 创意工坊”本尊

- **GitHub 仓库**：[dsh-market/dsh-market](https://github.com/dsh-market/dsh-market)
- **定位**：插件市场的“母舰”与可视化界面。
- **为什么必装**：
  在没有安装它之前，你给 DSH 装插件可能还要依赖命令行敲代码。而安装了 `dsh-market` 后，DSH 的 Web 设置中会直接多出一个原生的 **“Plugin Marketplace”** 面板！
- **核心体验**：
  - 像在 Steam 商店一样，直观浏览社区成百上千款插件；
  - 支持关键字搜索、分类筛选（工具/主题/提供方）、一键安装、更新与彻底卸载；
  - 只要你打算玩转 DSH 的插件生态，**它是你装好 DSH 后第一款必须安装的基础插件**。

---

### 2. `dsh-free-search`：零成本免费联网搜索，告别幻觉

- **GitHub 仓库**：[DDDMUC/dsh-free-search](https://github.com/DDDMUC/dsh-free-search)
- **定位**：免 Key、多引擎聚合的高自由度网络搜索插件。
- **解决痛点**：
  默认情况下，AI 智能体联网往往需要你绑定官方特定付费的搜索 API Key；一旦没买或者用第三方中转站，智能体就“断网”了，写代码遇到最新发布的框架版本时容易瞎编乱造。
- **核心亮点**：
  - **多引擎免 Key 白嫖**：内置支持 DuckDuckGo（Lite/HTML）、Bing、SearXNG 等多个无需注册、零费用的搜索源；
  - **多源平替与自动故障转移（Fallback）**：同时支持配置 Tavily、Exa、Perplexity、火山、百炼等备选源，遇到网络卡顿时自动切换备用引擎；
  - **快捷切换指令**：聊天框支持通过 `/free-search-engine` 呼出搜索源菜单，随心切换。

---

### 3. `dsh-providers-hub`：AI 编程账号与模型枢纽中心

- **GitHub 仓库**：[iJetLi/dsh-providers-hub](https://github.com/iJetLi/dsh-providers-hub)
- **定位**：聚合管理各路 AI 编程服务、账号池与中转网关。
- **解决痛点**：
  平时薅了多家平台的免费模型额度，或者手里有多个订阅账号，在客户端里来回切换配置极其繁琐。
- **核心亮点**：
  - **多账号池与无感轮换**：支持集中登录各家 AI Coding 服务，构建账号池，额度用尽时自动无感切号；
  - **静默保活与额度签到**：后台自动刷新登录凭据，支持部分平台的每日免费额度自动领取；
  - **本地 OpenAI 兼容网关**：把各种杂七杂八的模型渠道整合并暴露出一个标准的本地统一接口，省心至极。

---

### 4. `dsh-commandcode-provider`：Command Code 算力一键直连(本文作者开发，欢迎提交issue与pr)

- **GitHub 仓库**：[Victor-770/dsh-commandcode-provider](https://github.com/Victor-770/dsh-commandcode-provider)
- **定位**：为 DSH 注入 Command Code 渠道特性的模型提供方插件。
- **为什么值得装**：
  我们在[《AI 编程穷鬼套餐指南》](/pages/ai-coding-budget/)中提到，Command Code 拥有极具竞争力的低价模型与代码推理额度。这款插件专门打磨了 DSH 与 Command Code 渠道的适配。
- **核心亮点**：
  - **动态模型清单与实时拉取**：自动同步最新可用模型目录；
  - **规划感知路由（Plan-aware routing）**：能根据任务类型（日常问答 vs 深度推演）智能建议与调度匹配模型；
  - **多模态与推理档位控制**：原生支持图片多模态输入，并支持细粒度映射模型思考强度（Reasoning Effort）。

---

### 5. `dsh-better-sidebar`：把 DSH 爆改成全能开发工作台

- **GitHub 仓库**：[omdsh-dev/DSH-better-sidebar](https://github.com/omdsh-dev/DSH-better-sidebar)
- **定位**：开放式侧边栏工作台增强扩展。
- **解决痛点**：
  普通会话窗口只能看聊天打字，想看看 AI 改了什么文件、想开个终端跑命令，还得在多个窗口来回切来切去。
- **装上后的效果**：
  - **多面板侧边栏**：为 DSH 右侧/左侧注入类似 VS Code 的多功能侧边抽屉；
  - **内置文件渲染与轻量编辑**：点击 AI 提到的文件，直接在侧边栏高亮预览和快速编辑，无需跳出应用；
  - **集成多标签终端（Terminal Tabs）**：直接在界面侧栏开终端执行命令、查看运行输出；
  - **Git 图谱与分支状态**：直观查看改动文件的 diff 树和版本提交状态；
  - **插件基座能力**：其他第三方 UI 插件也能无缝挂载到它的侧边栏标签页中。

---

### 6. `dsh-reminder`：跨窗口完成提醒，放手去摸鱼(本文作者开发，欢迎提交issue与pr)

- **GitHub 仓库**：[Victor-770/dsh-reminder](https://github.com/Victor-770/dsh-reminder)
- **定位**：长程任务与人工确认（Human-in-the-loop）的桌面级提示器。
- **为什么实用**：
  DeepSeek Harness 跑长程任务（比如 Plan → Execute → Test 自主闭环）通常需要持续几分钟到十几分钟。你切到别的窗口看网页、写文档或摸鱼时，经常不知道它什么时候跑完了。
- **装上后的效果**：
  - **任务完成弹窗与清脆音效**：一旦任务全流程跑完，自动弹出桌面气泡与提示音，提醒你验收；
  - **关键权限阻断唤醒**：当智能体遇到敏感命令（如需要你手动确认执行某项操作）暂停等待时，立即提醒你回来确认，彻底消除“后台干等半小时才发现卡在确认弹窗”的尴尬。

---

### 7. `dsh-pocket`：把 DeepSeek Harness 装进口袋

- **GitHub 仓库**：[shaobeichen/dsh-pocket](https://github.com/shaobeichen/dsh-pocket)
- **定位**：局域网 / 穿透配对的手机移动端控制扩展。
- **核心玩法**：
  电脑在宿舍或实验室跑着庞大的长程重构任务，你想去食堂吃个饭或者去洗手间？
- **装上后的效果**：
  - 启动 `dsh web` 后，该插件会在终端或界面生成一个安全的**配对二维码**；
  - 拿出手机扫一扫（支持局域网直连或公网穿透通道），手机端立刻拥有一个轻量流畅的移动 Web 控制台；
  - 在手机上实时围观 DeepSeek 的思考流与终端执行步骤，甚至可以直接用手机打字给它下达下一步新指令！

---

### 8. `dsh-wallpaper-engine`：颜值正义！联动 Steam 动态壁纸

- **GitHub 仓库**：[elysia395/dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine)（社区另有轻量版 [sakuraaa667/dsh-wallpaper-engine](https://github.com/sakuraaa667/dsh-wallpaper-engine)）
- **定位**：真正的 Steam 玩家狂喜！将 Wallpaper Engine 动态壁纸直接搬进 DSH 界面。
- **为什么好玩实用**：
  谁说写代码一定要面对单调黑白枯燥的界面？DSH 作为自由度极高的智能体，连界面背景都能由你彻底主宰。
- **装上后的效果**：
  - **自动扫描 Steam 库**：无需手动到处找壁纸路径，插件能自动解析本地 Steam 的 `libraryfolders.vdf`，列出你在 Wallpaper Engine 里订阅下载的所有绝美壁纸；
  - **多种格式通吃**：支持 `.mp4` 动态视频壁纸、Web/HTML 互动网页壁纸以及 WebGL 场景渲染；
  - **毛玻璃与透明度控制**：自带 iOS 风格的液态玻璃（Liquid Glass）视觉层，支持调节背景暗化遮罩与对话面板透明度，既能欣赏二次元或赛博风动效，又完全不遮挡文字与代码阅读！

## 如何安装这些插件？

安装方式非常灵活，任选一种即可：

### 方式一：如果你已经安装了 `dsh-market`（推荐，最省心）
直接在 Web 界面的 **Settings → Plugin Marketplace** 中搜索插件名（如 `dsh-free-search` 或 `wallpaper-engine`），点击卡片上的 **Install** 即可，全图形化操作。
但注意某些插件未被该工具收录，只能采用命令行添加

### 方式二：通过 DSH 命令行直接添加
在你的系统终端（PowerShell 或 Bash）中，运行对应的添加命令：

```bash
# 1. 安装插件市场（工坊母舰）
dsh plugin --profile web add github:dsh-market/dsh-market

# 2. 安装免费搜索插件（免 Key 白嫖网络搜索）
dsh plugin --profile web add github:DDDMUC/dsh-free-search

# 3. 安装侧边栏增强工作台（IDE 多面板）
dsh plugin --profile web add github:omdsh-dev/DSH-better-sidebar

# 4. 安装长程任务提醒器（挂机防漏铃）
dsh plugin --profile web add github:Victor-770/dsh-reminder

# 5. 安装手机端远程联动插件（口袋控制台）
dsh plugin --profile web add github:shaobeichen/dsh-pocket

# 6. 安装提供商枢纽与 Command Code 接入
dsh plugin --profile web add github:iJetLi/dsh-providers-hub
dsh plugin --profile web add github:Victor-770/dsh-commandcode-provider

# 7. 安装 Steam Wallpaper Engine 动态壁纸扩展
dsh plugin --profile web add github:elysia395/dsh-wallpaper-engine
```

### 方式三：终极懒人法——直接吩咐 Agent，让它自己装！

既然你已经用上了 DeepSeek 智能体，为什么还要自己动手复制命令或翻设置？

作为拥有系统终端权限的长程智能体，**DeepSeek 完全可以自己给自己装插件**！你甚至不需要切出当前聊天窗口，直接在对话框里发一句人话指令：

> **“帮我把这个插件装上：`github:Victor-770/dsh-reminder`，并检查是否生效。”**
> 
> 或者：
> 
> **“帮我把 `dsh-free-search` 和 `dsh-better-sidebar` 安装到当前的 web profile 里。”**

DeepSeek 接收到指令后，会全自动在后台调用终端执行安装命令、校验安装日志，如果遇到报错还会自己纠错重试，装好后直接向你汇报：“*插件已安装就绪，已为您生效！*”——把“能动嘴绝不动手”贯彻到底。
