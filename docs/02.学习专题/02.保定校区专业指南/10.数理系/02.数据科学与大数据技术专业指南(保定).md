## 专业介绍

华电的大数据学习内容比较偏**统计**，由于是新专业，所以培养体系还在完善中，2025年才对培养方案做了一次大修改，删除了数学分析等数学专业的课程，新增内容更加偏工科。此专业是**工科专业**，但是华电数理系颁发**理学学士**学位。

详细课程请参考你这一届的培养方案（学校官网的培养方案不是最新），培养方案可在一体化平台查看。

## 知识技能掌握

最需要掌握的知识技能如下：

| 知识技能 | 范围/程度 |
| :---:   | :---: |
| 数学 | 作为工具理解、推导统计学原理、算法原理。考研数三建议125以上水平 |
| Python | 机器学习、深度学习、数据分析方向，主要的库有numpy、pandas、sklearn、pytorch、绘图相关<br>至少能够独立调用库完成任务 |
| 统计学 | 概率论、数理统计；理论基础扎实，能够手推大部分公式、定理 |
| AI | 不停留于网页聊天，能够调用API，使用Agent工具完成复杂任务 |
| 英语 | 最低四级，建议六级，有更高最求可以去雅思 |

## 项目经历

参加学校认可度高、专业相关度高的竞赛，一般可以是涉及深度学习、人工智能、时间序列等的竞赛、项目，如数模、新能源预测。

建议至少有一个最终成果不错的竞赛，两个及以上相关的竞赛/项目经历，也可以将课程大作业精心包装作为一个项目经历。

### 考研

此文章只写细分到专业的考研内容，更通用的考研内容请参考文章[考研](/pages/kaoyan/)。

2026届：考外校大部分失败，大部分人选择本校，具体数据未知，绝大部分人选择应用统计专业，有少数选择大数据、计算机。

应用统计开设院校多，绝大部分考英二数三432统计学，较简单。建议政治60+，英二75+，数三125+，专业课根据难度来定。建议至少1年时间来准备
