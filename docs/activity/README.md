# 首页“活动”公告

本目录的 Markdown **不会生成独立页面**，只作为首页“活动”栏的数据源。构建时会自动读取这里，按“活动开始日期”展示今天及以后的活动，过期活动会从首页隐藏。

## 新增一条活动

1. 复制 `_template.md`，把文件名改成活动名或日期，例如 `2026-09-12-讲座.md`。
2. 填写模板里的字段。
3. 提交 PR 或 push 到 `main`，GitHub Actions 会自动重新构建并更新首页。

## Frontmatter 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `title` | 是 | 活动名称 |
| `date` | 是 | 活动开始日期，`YYYY-MM-DD` |
| `end` | 否 | 跨天活动的结束日期，`YYYY-MM-DD` |
| `campus` | 否 | 校区，例如北京 / 保定 / 两校区 |
| `venue` | 否 | 活动地点 |
| `link` | 否 | 详情或报名链接 |
| `description` | 否 | 卡片标题下的一句话导语，会显示在正文上方 |

## 维护规则

- 一个活动一个文件；活动结束后可直接删除对应文件，也可以保留（仍会自动隐藏）。
- 文件名以 `_` 或 `.` 开头，以及 `README` 开头的文件会被忽略，不会显示在首页。

## 正文写在哪里

Frontmatter 下方的正文会作为“活动详情”**直接显示在首页活动卡片中**，支持常见 Markdown（段落、列表、加粗、链接等）。例如：

```markdown
报名截止到 9 月 10 日，**免费参加**，活动详情见[报名页](https://example.com)。
```

- 首页卡片会先显示标题、日期、地点，再显示这段正文。
- 如果同时写了 `description` 和正文，导语会显示在正文上方；两者重复时删掉其中一个即可。
- 正文建议保持简短，过长会让首页很长；需要超长全文或报名表单时，仍建议整理成普通 wiki 文章并在 `link` 中填写链接。
